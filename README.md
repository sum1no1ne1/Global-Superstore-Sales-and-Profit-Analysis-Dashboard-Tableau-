# Global-Superstore-Sales-and-Profit-Analysis-Dashboard-Tableau-

Global Superstore Sales and Profit Analysis Dashboard (Tableau)

This project presents an interactive business intelligence dashboard built using Tableau, based on the Global Superstore dataset. The objective of the project is to analyze sales performance, profitability, customer trends, and regional variations to support data-driven decision-making.

The dashboard provides a comprehensive view of business performance by integrating multiple analytical perspectives, including category-level analysis, geographical insights, and time-based trends.

Key Features

The project includes detailed analysis of sales and profit across different product categories, regions, and customer segments. It incorporates geographical visualizations to highlight performance across Indian states and US regions, enabling location-based insights.

Time series analysis is implemented to understand monthly trends and seasonal patterns in sales and quantity. The dashboard also includes comparisons between expected and actual sales and profit to identify performance gaps.

Multiple dashboards are interconnected to allow seamless navigation and provide different business perspectives, such as executive overview, category performance, and KPI tracking.

Tools and Technologies

The project is developed using Tableau Desktop. It also involves data preprocessing steps such as data cleaning, handling missing values, removing duplicates, and creating derived columns for better segmentation and analysis.

Dashboard Modules

The project consists of several dashboards, including an executive overview of sales and profit, category performance analysis, monthly KPI tracking, sales versus profit by manager, regional performance dashboards, and profit ratio analysis.
